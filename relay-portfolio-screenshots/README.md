# Relay portfolio screenshots

All screenshots were captured from the live Demo Mode deployment at 1600 × 1000 pixels. Demo records are isolated to the capture browser.

## Recommended portfolio order

1. `01-dashboard-overview.png` — Primary hero image. Shows portfolio KPIs, charts, navigation, and the overall visual system.
2. `04-gantt-project-timeline.png` — Strongest technical feature image. Shows task metrics, filtering, timescale controls, progress bars, and live-update status.
3. `06-reports-document-control.png` — Shows document review states, metadata, reviewer notes, filtering, and document actions.
4. `02-project-portfolio.png` — Shows project search/filtering, review workflow, KPIs, and project cards.
5. `05-calendar-scheduling.png` — Shows project event scheduling and upcoming-event tracking.
6. `07-team-management.png` — Shows personnel metrics, search, roles, availability, and profile access.
7. `08-notifications-center.png` — Shows activity monitoring, filters, deadline access, and project forecasting.
8. `03-create-project-workflow.png` — Supporting image for CRUD/form design and validation workflows.
